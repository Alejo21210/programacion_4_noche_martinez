# modulo07_layouts

Aplicacion Flutter reimaginada como una clinica veterinaria para mostrar ejemplos de layout con una vision mas visual y amigable.

## Tematica

- Contenedores, columnas, filas, stacks y wraps adaptados a una recepcion veterinaria.
- Tarjetas de seguimiento de pacientes, estados de atencion y avatares de mascotas.
- Colores calidos y profesionales para reforzar la identidad de la clinica.
