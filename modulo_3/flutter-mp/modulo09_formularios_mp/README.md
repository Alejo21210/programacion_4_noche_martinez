# modulo09_formularios

Aplicacion Flutter reimaginada como una clinica veterinaria con formularios y vistas de pacientes.

## Caracteristicas

- Registro de pacientes con campos para nombre, especie, edad y motivo de visita.
- Listado y busqueda de pacientes con acciones de favorito y cierre de ficha.
- Tema veterinario con colores de salud, cuidado y atencion.

## Ejecutar

1. Asegurate de tener Flutter instalado.
2. Desde esta carpeta ejecuta:
   - `flutter pub get`
   - `flutter test`
   - `flutter run`
