# modulo08_material3

Aplicacion Flutter reimaginada como una clinica veterinaria con ejemplos de Material 3.

## Caracteristicas

- Tema veterinario con colores de salud, cuidado y atencion.
- Pantallas de tema, turnos, botones, navegacion y dialogos adaptadas al contexto de una clinica.
- Ejemplos de UI para gestionar pacientes, citas y alertas.

## Ejecutar

1. Asegurate de tener Flutter instalado.
2. Desde esta carpeta, ejecuta:
   - `flutter pub get`
   - `flutter test`
   - `flutter run`
