# modulo10_riverpod

Aplicación de ejemplo de Riverpod reimaginada como una clínica veterinaria.

## Descripción

Este módulo conserva la lógica de Riverpod para gestionar una lista de pacientes, pero ahora presenta fichas de atención, favoritos y acciones de registro en un contexto de clínica veterinaria.

## Estructura

- `lib/main.dart`: punto de entrada de la app con el tema veterinario.
- `lib/providers/servidores_provider.dart`: estado global con pacientes de ejemplo.
- `lib/screens/pantalla_servidores.dart`: pantalla principal de pacientes.
