# modulo11_gorouter

Aplicación de ejemplo de GoRouter reimaginada como una clínica veterinaria.

## Descripción

Este módulo conserva la estructura de navegación con rutas, parámetros y ShellRoute, pero ahora presenta pacientes, fichas clínicas y navegación entre pantallas de una clínica veterinaria.

## Estructura

- `lib/main.dart`: punto de entrada con el tema veterinario.
- `lib/router/`: definición de rutas para los pasos de GoRouter.
- `lib/screens/`: pantallas de inicio, pacientes, detalle, historial y ajustes.
