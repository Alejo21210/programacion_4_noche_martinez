# modulo06_widgets

Aplicación Flutter reimaginada como una clínica veterinaria para mostrar widgets básicos y su comportamiento visual.

## Temática

- Pantallas y textos adaptados a una clínica veterinaria.
- Botones, tarjetas, chips y progreso con colores cálidos y profesionales.
- Ejemplos de estado, temporizadores y contexto de pantalla orientados a atención de mascotas.
